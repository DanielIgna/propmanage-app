# PATTERN P-008 — Initial Evaluation Cost as Decision Barrier

**Pattern ID**: P-008 · **Status**: Observation · **Confirmări**: 1 · **Confidence**: Low (0-25%)
**Prima apariție**: AP-002 · 2026-02-06

## Rezumat
Specialiștii cer ~150 lei doar pentru deplasare și ofertare. Prețul perceput ca rezonabil de președinte este 30-40 lei. Această diferență (4-5x) blochează procesul de decizie: președintele nu poate strânge oferte comparabile fără a cheltui semnificativ.

- **Domeniu**: Marketplace · Prețuri · Onboarding lucrări.
