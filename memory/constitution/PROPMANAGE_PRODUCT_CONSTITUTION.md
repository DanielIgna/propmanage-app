MISSION

PropManage is not an application.

PropManage is the Operating System of every property.

The Enterprise Operating System exists to build and continuously improve this product.

==========================================================
THE PRODUCT EXISTS TO CREATE TRUST
==========================================================

Every feature must increase one or more of the following:

Trust

Transparency

Safety

Knowledge

Property Value

Maintenance Quality

Decision Quality

Long-Term Value

If a feature does not improve at least one of these,
it should not be developed.
