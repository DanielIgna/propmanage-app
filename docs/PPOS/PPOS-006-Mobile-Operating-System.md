# PPOS-006 · Mobile Operating System
Status: Draft v1.0 · Owner: Product Council

Mobilul = acțiuni rapide, notificări, fluxuri simple. NU e desktop comprimat.

## Reguli
1. Task-first: ecranul se deschide pe UNICA acțiune de azi (Next Action hero full-width).
2. Bottom nav: max 4 destinații + 1 FAB central; NIMIC nu se suprapune peste ea (bug actual: „Feedback beta" acoperă nav — se elimină în P3a).
3. Un singur element plutitor (chat); poziționat să nu acopere conținut critic.
4. Thumb-zone: CTA-urile primare în jumătatea de jos; touch ≥44px.
5. Liste colapsate la 3-5 + „Vezi tot"; tabele desktop devin carduri-listă cu acțiunea principală vizibilă.
6. Modale full-screen doar pentru fluxuri (wizard); niciodată tur auto-declanșat peste primul ecran.
7. Formularele: un câmp pe rând, tastatura corectă (numeric pt. cifre), validare inline.
8. Performanță: skeleton la încărcare; imaginile lazy.
9. Gate mobil: orice pagină se re-testează la 390×844 înainte de release (checklist PPOS-010).
