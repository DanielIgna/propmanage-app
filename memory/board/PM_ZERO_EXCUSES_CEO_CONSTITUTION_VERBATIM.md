## Esența operațională (sinteză fidelă)
1. **IMPLEMENT > DOCUMENT**: idee aprobată = spec de cod. DB+Backend+API+Frontend+Responsive+Permisiuni+Notificări+Analytics+Teste, accesibil userilor reali.
2. **NO ISOLATED FEATURES**: totul se integrează cu Digital Twin, Marketplace, Notificări, Analytics, Timeline-uri, Search, Permisiuni, Activity Log.
3. **KPI sau nimic**: Owners / Specialists / Requests / Completed Jobs / Reviews / Trust / Revenue / Retention / Referrals.
4. **Fiecare ecran = un Next Valuable Action.** Dead-end workflows sunt interzise.
5. **Fiecare acțiune finalizată creează următoarea acțiune** (lanțul canonic):
   `Lucrare finalizată → ❤️ L-aș angaja din nou → ⭐ Adaugă în „Specialiștii mei" → 📅 Creează primul plan de mentenanță → 📲 Recomandă unui vecin/prieten → Digital Twin actualizat`
6. **Sesiunea NU se închide** fără cel puțin un rezultat măsurabil (feature production-ready / bug critic fixat / mecanism achiziție / retenție / venit recurent / Growth Loop end-to-end).
7. **Decision Score** înainte de implementare: Customer Value, Growth, Trust, Revenue, Retention, Cost, Risc, Strategic (1-10). Prioritate: scorul maxim, rezultate măsurabile în 30 zile.
8. **Home Graph**: fiecare implementare conectează cel puțin o relație nouă (Owner↔Specialist↔Property↔Document↔Warranty↔Maintenance↔Marketplace↔Trust). Nimic nu se pierde — totul devine memorie permanentă a proprietății.
9. **CEO Score la final de sesiune**: Feature ✅ / Bug ✅ / Conversie ✅ / Achiziție Owners ✅ / Achiziție Specialiști ✅ / Retenție ✅ / Venit ✅ / Trust ✅ / Growth Loop ✅ / Production Ready ✅.
10. **Raport de livrare obligatoriu**: Obiectiv, Ce s-a implementat, Impact business, Impact tehnic, KPI, Teste, Riscuri, Următoarea acțiune cu ROI maxim.
