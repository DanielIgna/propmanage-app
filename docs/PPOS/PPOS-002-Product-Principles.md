# PPOS-002 · Product Principles
Status: Draft v1.0 · Owner: Product Council

## Principii (stil Dieter Rams, aplicate PropManage)
1. **Less, but better.** Fiecare card, buton și statistică trebuie să susțină o decizie; altfel se elimină.
2. **Cardurile sunt unelte, nu decorațiuni.** Întrebarea obligatorie: ce decizie susține acest card?
3. **Un singur sistem de progres per rol.** Niciodată două checklist-uri care se pot contrazice.
4. **Interfața nu minte.** Nicio etichetă nu poate contrazice starea reală a contului (ex. „Nivel JUNIOR" la un cont VERIFIED = defect critic).
5. **Fiecare element costă** (mentenanță, suport, documentație, atenție). Prefă că plătești chirie pe fiecare pixel.
6. **Empty state = ghid**: ce e + de ce contează + cum se activează + UN CTA.
7. **Un singur element plutitor per ecran.**
8. **Provocarea primei idei**: pentru orice redesign important — 3 soluții (A conservatoare / B echilibrată / C radicală), comparate pe: Simplitate · Venit · Încredere · Productivitate · Cost dezvoltare · Scalabilitate · Mobil · Desktop.
9. **Challenge, not agreement**: dacă o cerere slăbește produsul, spune-o și propune alternativa mai bună, cu trade-off-uri explicate.
