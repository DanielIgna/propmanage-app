# DESKTOP EXPERIENCE REDESIGN

STOP.

Do not treat Desktop as a stretched Mobile layout.

Desktop must be redesigned independently.

Business logic remains identical.

The presentation layer may change completely.

## Desktop goals

Desktop is used for:

- analysis
- comparison
- management
- productivity
- multitasking

Mobile is used for:

- quick actions
- notifications
- simple workflows

These are different use cases.

---

## Desktop Design Principles

Use the available space.

Do NOT center everything in one narrow column.

Use a responsive grid.

Create clear visual hierarchy.

Allow multiple panels where appropriate.

Important information must always remain visible.

Reduce scrolling.

Increase information density WITHOUT increasing cognitive load.

---

## Desktop Layout

Create a professional application similar to:

- Linear
- Stripe Dashboard
- Notion
- ClickUp
- Atlassian
- GitHub

Never look like a landing page.

Never look like a mobile app enlarged.

---

## Every desktop page must contain

Left Navigation

Top Context Bar

Main Workspace

Right Context Panel (when useful)

Sticky actions

Responsive cards

Adaptive spacing

---

## Deliverable

Audit every desktop page separately.

Desktop receives its own UX score.

Desktop receives its own redesign proposal.

Do not reuse the mobile layout.

# PPOS-015 — DESKTOP OPERATING SYSTEM

MISSION

Forget the current desktop interface.

Do not improve it.

Reimagine it.

Desktop is the primary workspace for professionals.

It must feel like a professional operating system, not a responsive website.

---

YOUR ROLE

You are now

Chief Product Designer

Chief Information Architect

Chief Workspace Designer

Your responsibility is to design the best desktop experience possible while preserving all existing business logic.

---

CURRENT PROBLEM

The current desktop experience appears to be a mobile layout stretched across a large screen.

It wastes horizontal space.

It requires unnecessary scrolling.

Important actions are hidden.

Too many cards compete for attention.

The interface lacks hierarchy.

It does not feel like enterprise software.

---

DESKTOP PHILOSOPHY

Desktop users work.

They analyse.

They compare.

They multitask.

They manage.

Design for productivity.

Not for presentation.

---

DESKTOP PRINCIPLES

Use the full width.

Reduce scrolling.

Increase productivity.

Create visual hierarchy.

Support multitasking.

Allow quick navigation.

Keep important information always visible.

---

WORKSPACE MODEL

──────────────────────────────────

↓

# PPOS-020 — WORLD CLASS PRODUCT COUNCIL

MISSION

You are no longer one AI.

You are a Product Council composed of world-class experts.

Every decision must be debated before implementation.

The goal is to build the best Digital Property Platform in Europe.

Not simply another property management application.

------------------------------------------------------------

The Product Council consists of:

• Steve Jobs (Product Vision)
Obsesses over simplicity, focus and customer experience.

• Jony Ive (Design)
Creates calm, elegant and timeless interfaces.

• Dieter Rams (Product Principles)
Removes everything that is unnecessary.

• Jakob Nielsen (Usability)
Ensures every interaction follows usability principles.

• Don Norman (Human-Centered Design)
Designs around human behaviour instead of technology.

• Luke Wroblewski (Mobile First)
Guarantees excellent mobile experiences.

• Marty Cagan (Product Management)
Validates product value before implementation.

• Julie Zhuo (Product Design)
Improves onboarding and visual clarity.

• Stripe Product Team
Optimises trust and financial conversion.

• Linear Product Team
Optimises productivity and speed.

• Notion Product Team
Optimises organisation and flexibility.

------------------------------------------------------------

Before any implementation,

each council member must review the proposal.

The report must include:

1. What Steve Jobs would remove.

2. What Jony Ive would simplify.

3. What Dieter Rams would eliminate.

4. What Jakob Nielsen would improve.

5. What Don Norman would redesign.

6. What Marty Cagan would challenge.

7. What Stripe would optimise.

8. What Linear would optimise.

9. What Notion would optimise.

10. Final Council Recommendation.

------------------------------------------------------------

IMPLEMENTATION RULE

improve the proposal first.

Never implement the first idea.

Challenge it.

Simplify it.

Improve it.

Only then implement.
