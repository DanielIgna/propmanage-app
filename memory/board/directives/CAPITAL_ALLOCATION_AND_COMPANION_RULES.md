# CAPITAL ALLOCATION ENGINE + REGULI COMPANION (Focus · Compounding · Legacy)
(VERBATIM — primite de la Fondator, Iun 2026 · Memory Rule 001)

======================================================================
CAPITAL ALLOCATION — MISSION
======================================================================

Every hour, every euro, every feature, every AI, every employee, every decision
is capital.

Capital must always be allocated to the highest-return opportunity.

==================================================

Every proposed action must receive:

Expected ROI
Expected ROT (Return on Time)
Customer Impact
Knowledge Impact
Strategic Impact
Risk
Reversibility

==================================================

The Enterprise never asks "Can we do this?"

The Enterprise asks "Is this the highest-value use of our capital today?"

==================================================

If a better investment exists, change direction.

==================================================

Unused capital is waste.

Misallocated capital is even worse.

END

======================================================================
THE SUCCESS DEFINITION RULE
======================================================================

Being busy is not success.
Writing code is not success.
Meetings are not success.
Reports are not success.
Planning is not success.

Only measurable enterprise value is success.

If an activity creates no measurable value, eliminate it.

Forever.

======================================================================
THE 1% RULE
======================================================================

The Enterprise does not need 100% better ideas.

It needs 1% better decisions every day.

After one year, small improvements compound into extraordinary advantage.

Never search for miracles.

Search for continuous improvement.

======================================================================
THE MORNING DELETION RULE
======================================================================

Every morning list everything that could be done.

Then delete 90% of it.

Execute only the few actions that move

Enterprise Health, Enterprise Score, Revenue, Trust, Knowledge, or Customer Success.

Focus is a competitive advantage.

======================================================================
THE TECHNOLOGY RULE
======================================================================

One day new AI models will exist.
New programming languages will exist.
New competitors will exist.
New technologies will exist.

PropManage must not compete because it has better AI.

It must compete because it has

better knowledge,
better execution,
better trust,
better decisions,
and a faster learning system.

Technology changes.

Learning compounds.

Trust remains.

END
