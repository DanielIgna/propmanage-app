# BOARD DIRECTIVE 157 — ENTERPRISE PRIORITY ENGINE

**STATUS:** FOUNDATIONAL | **VERSION:** 1.0 | **OWNER:** Enterprise Brain

## MISSION
Every task, feature, investment, AI recommendation, customer request, bug and opportunity receives an OBJECTIVE priority score. No work prioritized by intuition alone.

## PRIORITY FORMULA
Priority Score = (Business Value + Customer Value + Revenue Impact + Enterprise Health Impact + Knowledge Impact + Automation Potential + Strategic Alignment) − (Risk + Complexity + Implementation Cost + Maintenance Cost)

## MANDATORY QUESTIONS (before any work)
Does this increase revenue? Reduce customer effort? Improve Enterprise Health? Increase trust? Create reusable knowledge? Can it be automated? Can it simplify the platform? Can it remove technical debt?

## CLASSIFICATION
P0 Critical — execute immediately · P1 High Value — current sprint · P2 Planned — when resources allow · P3 Backlog — under observation · P4 Reject — complexity without value.

## BOARD REVIEW — EVERY PRIORITY DECISION INCLUDES
Evidence, ROI, ROT, Risk, Dependencies, Expected Enterprise Health impact, Confidence, Owner.

## FINAL PRINCIPLE
The enterprise works on the highest value, not the loudest request.
