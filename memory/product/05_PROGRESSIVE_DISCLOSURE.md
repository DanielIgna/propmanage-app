# 05 · PROGRESSIVE DISCLOSURE — matricea de dezvăluire
Regula: interfața crește cu utilizatorul, pe bază de DOVEZI din cont (nu etichete). Hidden > Disabled > Confusing.

## Client (declanșatoare = date reale)
| Etapă | Declanșator | Se deblochează | Rămâne ascuns |
|---|---|---|---|
| J0 | cont creat | Adaugă proprietatea | tot |
| J1 | ≥1 proprietate | Cartea casei (document) | marketplace, AI, twin |
| J2 | ≥1 document | Solicită audit | |
| V | audit finalizat / verificat | Sănătatea casei, Recomandări, Istoric | |
| P | twin sau abonament | Digital Twin, Marketplace, Mentenanță, Copilot AI | — |

## Specialist (tier existent ENTRY→TOP; UN sistem de progres)
| Tier | Vede | Nou deblocat |
|---|---|---|
| ENTRY | 3 pași + oportunități (model existent) | — |
| JUNIOR | + istoric lucrări | badge-uri |
| VERIFIED | + cereri noi, recenzii, șabloane | filtre |
| ADVANCED | + Cockpit pipeline, căutări salvate | matching prioritar |
| PREMIUM | + Capabilități, profil premium | rapoarte |
| TOP | + tot | support prioritar |

## Reguli
1. Elementele blocate NU se listează. Maxim 1 rând: „Următoarea deblocare: X (la criteriul Y)".
2. Niciun checklist nu poate contrazice starea reală (ex. „primul lead 0/1" la 27 lucrări = interzis).
3. Onboarding-ul dispare definitiv după finalizare (nu rămâne colapsat).
4. Turul ghidat nu se autodeclanșează; devine „?" on-demand.
