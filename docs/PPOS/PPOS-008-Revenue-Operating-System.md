# PPOS-008 · Revenue Operating System
Status: Draft v1.0 · Owner: Product Council

1. Funnel monetizat: proprietate → document → **AUDIT (prima plată)** → twin → abonament/marketplace → listare verificată (comision). Pricing (Constituție): Audit → listare gratis; Audit+Twin → 0% comision.
2. Slotul Next Action = motorul de venit: fiecare etapă împinge organic spre următoarea achiziție, cu valoarea explicată (expected_gain).
3. Tranzacția întâi: plată în așteptare = singurul CTA (reduce time-to-cash). Upsell-ul nu apare peste o tranzacție activă.
4. Încrederea = conversie: eliminarea contradicțiilor, jargonului și stărilor imposibile este cea mai ieftină optimizare de conversie (P3a).
5. Metrici de urmărit (Beta Cockpit există): Activation rate (J0→J1), TTFV, conversie audit, conversie twin, retenție, NPS/VoC.
6. Orice element de venit trece testul: crește activarea/conversia/retenția/abonamentele? (CRO în Product Council).
