# BOARD DIRECTIVES 069–070 — ENTERPRISE VALUE OFFICE (EVO)
**Status: PERMANENT · STRICT CONFIDENȚIAL (doar Founder + Chairman) · Iunie 2026**

## Misiune
Evaluarea oficială și permanentă a PropManage. Fiecare Sprint = investiție. Fiecare Epic = proprietate intelectuală. Fiecare feature aprobat = activ al companiei. EVO devine sursa oficială de adevăr pentru valoarea companiei.

## Componente obligatorii
1. **Development Ledger** — per Sprint: dată, versiune, epic, features, fișiere, complexitate, ore estimate (dev/QA/UX/arhitectură/documentație/AI), echipă umană echivalentă, credite consumate.
2. **European Development Cost** — cost de înlocuire la rate medii europene per rol (Founder, PO, BA, Solution Architect, Backend/Frontend/Mobile, UI/UX, QA, DevOps, Security, AI Engineer, Technical Writer, PM).
3. **Intellectual Property Register** — inventar permanent: arhitectură, cod, business logic, prompt library, AI Executive Board, directive, documentație, Digital Twin Engine, Verified Properties Engine, Marketplace, Trust Engine, Knowledge Graph, Analytics, Design System, playbooks, proceduri. Per activ: versiune, owner, dependențe, valoare estimată, cost înlocuire, importanță comercială/strategică, avantaj competitiv.
4. **Company Valuation** — continuu, 3 scenarii: Conservative / Realistic / Strategic, cu presupuneri explicate.
5. **Executive Dashboard** — valoare platformă, valoare IP, cost înlocuire, ore, echipă echivalentă, investiție, credite, readiness (comercial/operațional/franciză/tehnologic).
6. **Franchise Readiness Report** — maturitate (platformă/business/tech/operațional/comercial), suport/training/documentație, efort onboarding, ROI partener, break-even, riscuri/oportunități expansiune.
7. **Raport lunar** + **Investor Package** (confidențial: sumar executiv, tehnologie, business, poziție de piață, avantaje, investiție, cost înlocuire, evaluare, oportunități, expansiune, franciză, SWOT, riscuri).

## VALUATION GOVERNANCE (nenegociabil)
Orice estimare financiară include: metodologie, presupuneri, nivel de încredere (%), referințe comparabile, marjă de eroare. Valorile fără date exacte se marchează ESTIMARE. Proiecțiile nu se prezintă ca fapte. Separă strict: cost istoric / cost înlocuire / valoare de piață / valoare strategică / valoare comercială / venit actual / venit potențial. **Credibilitatea evaluării > mărimea evaluării. Niciodată nu umfla cifrele.**
