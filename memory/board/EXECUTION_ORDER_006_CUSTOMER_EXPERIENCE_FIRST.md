UX LAWS (MANDATORY)

Every page must comply with

Hick's Law

Reduce choices.

--------------------------------------

Miller's Law

Show information in manageable chunks.

--------------------------------------

Fitts' Law

Primary buttons must be large,
close,
easy to reach,

--------------------------------------

Jakob Nielsen Heuristics

Visibility of status

Consistency

Recognition over recall

Error prevention

User control

Feedback

Simple language

--------------------------------------

Tesler's Law

Keep complexity inside the system,
never inside the user's mind.

--------------------------------------

Gestalt Principles

Group related information.

Separate unrelated information.

Use whitespace.

Use hierarchy.

--------------------------------------

Progressive Disclosure

Never expose advanced functionality
before it becomes useful.

--------------------------------------

Doherty Threshold

Interface feedback under 400ms.

Skeleton loaders.

Optimistic UI.

--------------------------------------

Peak-End Rule

Create memorable first impression.

Create memorable completion.
