# PM-200 TRUST MARKETPLACE

Redesign the Marketplace positioning.

Do NOT change the Marketplace concept.

Strengthen it.

New positioning:

"Marketplace-ul profesioniștilor recomandați de proprietari."

Keep:

- Marketplace
- Reviews
- Ratings

Enhance them with a Trust Layer.

Every specialist profile should communicate:

• Reviews
• Average Rating
• Number of completed jobs
• Number of recommending property owners
• Would hire again (%)
• Verification status
• Portfolio
• Response time
• Completion rate

Review System:

Every completed job asks:

1. Rate the work.
2. Leave a review.
3. Would you hire this specialist again? (Yes / No)
4. Would you recommend this specialist to another property owner? (Yes / No)

These answers contribute to the Trust Score.

Design a Community Trust Score that combines:

- Reviews
- Ratings
- Repeat recommendations
- Completed jobs
- Profile verification
- Response quality

Avoid fake reviews.

Avoid ranking manipulation.

Reward long-term trust instead of short-term popularity.
