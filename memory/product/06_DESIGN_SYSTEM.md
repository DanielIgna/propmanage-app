# 06 · DESIGN SYSTEM (reguli de prezentare PPOS)
Tokens/temele existente rămân (dark + lime #d4ff3a / clientv2 light). Reguli noi de utilizare:

1. **Un singur buton primar (lime plin) per ecran.** Orice alt buton: ghost/outline/text-link.
2. Max 2 badge-uri pe un card public; scoruri interne (50/80, „reco") nu apar public.
3. Textele de sistem se traduc uman (niciodată snake_case/EN în UI client).
4. Rating fără recenzii → „Nou pe platformă" (niciodată ★5 (0)).
5. Liste/timeline: colaps la 3-5 + „Vezi tot (N)".
6. Un singur element plutitor per ecran (chat). Bottom nav mobil: nimic nu se suprapune peste el.
7. Empty state = ce e + de ce + cum + UN CTA.
8. Touch targets ≥44px; text hierarchy: H1 text-4xl→6xl, body text-sm/base.
