# MEMORY RULES — ENTERPRISE MEMORY GOVERNANCE

## Memory Rule 001 (VERBATIM — primit de la Fondator, Iun 2026)
No governance document may be summarized.
Governance documents must always be stored verbatim.
Only derived documents may be summarized.
