# 07 · REVENUE UX
Principiu: venitul crește prin claritate, nu prin expunere de feature-uri.

- Funnel-ul monetizat: proprietate → document → **AUDIT (plătit)** → twin → abonament/marketplace → listare verificată (comision).
- Slotul „Next Action" este motorul de venit: fiecare etapă împinge organic spre următoarea achiziție.
- Upsell-ul (slot 6) apare DOAR când nu există tranzacție activă neterminată; niciodată CTA primar concurent.
- Tranzacția întâi: plată în așteptare = singurul CTA de pe ecran (reduce time-to-cash).
- Trust = conversie: eliminarea contradicțiilor (S3), a jargonului (S6) și a datelor imposibile (S7) este cea mai ieftină creștere de conversie disponibilă.
- Pricing model (Constituție): Audit → listare gratis · Audit+Twin → comision 0%.
